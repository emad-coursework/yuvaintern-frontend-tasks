Key Engineering Improvements

Semantic Landmarks

Uses <header>, <nav>, <main>, <section>, and <footer> with clear heading hierarchy so assistive tech users can jump directly to content.

Keyboard & Focus Rings

Every interactive link, button, and disclosure summary provides a high-contrast :focus-visible outline and logical tab order.

Zero-JS Native Disclosures

Replaces heavy accordion scripts with native HTML <details> and <summary> elements for instant keyboard support and zero JS parse cost.

Technical Optimization Breakdown

1. CSS Efficiency & Critical Path
